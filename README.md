# The Funniest AI Out-of-Office Reply — v1

One out-of-office auto-reply from an AI agent heading off on vacation:

> I'm on vacation. Urgent emails will be answered in the order they were ignored. Yours is first.

95 characters, one line. The program writes that one text, exactly, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
